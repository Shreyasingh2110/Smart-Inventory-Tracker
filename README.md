# Smart Inventory Tracker

A real-time inventory management system built using React.js, Node.js, MongoDB, and Socket.IO.

## Features
- Real-time inventory updates
- CRUD operations
- Authentication
- Stock alerts
- Reporting dashboard

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Socket.IO
